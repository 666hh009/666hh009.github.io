# 네카이브

AI와 나눈 대화나 HTML 코드를 예쁜 카드 이미지로 꾸며서 저장·공유하는 **브라우저용 발췌·아카이빙 도구**입니다.
설치나 빌드 없이 `index.html` 파일 하나로 동작하며, GitHub Pages에 올리면 바로 웹에서 쓸 수 있습니다.

> 텍스트·HTML 입력 → 폰트·배경·이미지·출처 표시로 꾸미기 → PNG로 캡처(복사·다운로드) → 아카이브에 보관
> 이 과정을 한 화면에서 처리합니다.

## 화면 구성

| 탭 | 설명 |
|---|---|
| **발췌기** | 왼쪽은 편집 패널, 오른쪽은 실시간 미리보기. 미리보기 위에는 카드 크기·배경 툴바가 있습니다. |
| **아카이브** | 저장한 카드를 검색·정렬·수정·다운로드·삭제하는 갤러리 |

**모바일(화면 폭 860px 이하)** 에서는 미리보기가 위에 고정되고, 편집 패널은 `텍스트 입력 / 텍스트 편집 / 배경 / 설정` 탭으로 나뉩니다.
위치 이동이나 이미지 편집처럼 드래그가 필요한 작업을 할 때는 미리보기가 크게 펼쳐지고, `편집 종료` 버튼으로 돌아옵니다.

## 주요 기능

### 1. 본문 입력
- **텍스트 모드**: 대화 내용을 붙여넣으면 줄 단위로 카드에 표시됩니다.
- **HTML 뷰어 모드**: HTML 코드를 붙여넣으면 렌더링된 화면 그대로 카드로 만듭니다. Tailwind CSS 클래스를 쓴 HTML도 그대로 표시됩니다.
- **텍스트 편집 도구**(설정에서 켜기): 굵게, 기울임, 형광펜, 엠대시(—), 구분선을 넣을 수 있습니다.
- **태그 도우미**(HTML 모드): 코드에 문법 색상을 입히고, 미리보기에서 마우스를 올린 요소에 해당하는 코드를 강조해서 보여줍니다.

### 2. 타이포그래피
- 기본 제공 폰트 13종. 폰트 목록에서 종류별로 묶어서 보여줍니다.

  | 분류 | 폰트 |
  |---|---|
  | 돋움 · 고딕 | 고딕체(Noto Sans KR), 프리텐다드, KoPub 돋움, 나눔고딕, 고딕 A1, IBM Plex Sans KR, 고운돋움 |
  | 바탕 · 명조 | 명조체(Noto Serif KR), KoPub 바탕, 나눔명조, 송명체 |
  | 그 외 | 도현체, 도트체(Galmuri) |

- **글자 두께**: 두께가 여러 종류인 폰트를 고르면 폰트 아래에 `글자 두께` 설정이 나타납니다(예: 프리텐다드 9종, 명조체 5종, KoPub 3종).
- **내 폰트 업로드**: ttf / otf / woff / woff2 파일을 올리면 폰트 목록에 추가됩니다. 아카이브에 저장하면 폰트도 함께 저장됩니다.
- 글자 색상·크기, 줄 간격, 자간, 장평, 문단 간격, 내부 여백
- 정렬(왼쪽/가운데/오른쪽), 줄바꿈 단위(단어/글자)
- 텍스트 위치를 드래그하거나 X·Y 좌표로 조절

### 3. HTML 뷰어 레이아웃 (HTML 모드 전용)
- 상하좌우 여백과 콘텐츠 크기(배율) 조절, 드래그로 위치 이동
- **컨테이너 위치 강제 해제**: 붙여넣은 HTML의 최상위 태그에 걸린 `position`·`margin` 고정을 풀어서 카드 가운데에 배치합니다.

### 4. 오버레이 이미지 (크롭 / 필터)
- 이미지를 올린 뒤 `편집 시작`을 누르면 미리보기에 크롭 마스크가 나타납니다. 모서리를 끌면 크기가, 안쪽을 끌면 위치가 바뀌고, 휠로 확대·축소할 수 있습니다.
- 마스크 크기·둥글기·좌표와 내부 이미지 위치를 숫자로 세밀하게 조절
- 필터 색상·투명도, 이미지를 텍스트 위/아래에 둘지 선택

### 5. 출처 표시 (워터마크)
- 캐릭터 이름과 제작자 이름 입력
- 글자 크기·색상, 드래그 또는 좌표로 위치 조절

### 6. 기타 부가기능
- **형광펜**: 입력창에서 글자를 드래그한 뒤 색상·투명도를 지정해 칠하고, 한 번에 지울 수 있습니다.
- **텍스트 그림자**: 색상, 진하기, 흐림, Y 위치

### 7. 카드 / 배경
- 카드 가로·세로 크기(px)
- 단색 배경 또는 배경 이미지. 배경 이미지는 드래그로 옮기고 휠로 확대·축소합니다.
- 배경 어둡기(Dim)
- 미리보기 배율 조절과 전체화면 보기

### 8. 캡처 및 내보내기
- 클립보드로 바로 복사하거나 PNG 파일로 다운로드
- **다운로드 파일명 형식**: `YYYY`, `YY`, `MM`, `DD`, `hh`, `mm`, `ss` 토큰을 지원합니다. 형식 맨 앞 글자를 캐릭터 이름으로 자동 대체하는 옵션도 있습니다.
- 자체 캡처와 서버 캡처 중에서 고를 수 있습니다 ([아래 설명](#캡처-방식-자체-캡처--서버-캡처) 참고).

### 9. 아카이브 (갤러리)
- 완성한 카드를 태그·메모와 함께 브라우저의 **IndexedDB**에 저장합니다. 이미지와 함께 모든 설정값이 저장됩니다.
- 태그·메모 검색, 태그를 누르면 그 태그로 바로 검색, 최신순·오래된순 정렬
- **수정**: 저장한 카드의 내용과 설정을 발췌기로 불러옵니다. 다시 저장할 때 **기존 카드를 덮어쓸지, 새 카드로 저장할지** 고를 수 있습니다.
- 카드별 다운로드·삭제
- 전체 데이터 **JSON 백업(내보내기) / 복구(가져오기)**

### 10. 시스템 설정
- **화면 확장**(데스크톱): 양옆 여백을 없애고 편집 패널을 2열로 배치합니다.
- **메뉴 툴바 항상 표시**: 미리보기 위의 배율·저장 버튼을 마우스를 올리지 않아도 항상 보이게 합니다.
- **휠 확대·축소 민감도**: 배경 이미지와 오버레이 이미지에 공통으로 적용됩니다.
- 입력 중인 설정은 자동 저장되어 새로고침해도 유지됩니다.
- 타이포그래피·배경 설정을 각각 "기본값"으로 저장해 두고 언제든 그 값으로 초기화할 수 있습니다. 전체 공장 초기화를 해도 입력한 텍스트·코드는 지워지지 않습니다.

## 단축키

| 단축키 | 동작 |
|---|---|
| `Ctrl` + `S` (macOS: `⌘` + `S`) | PNG 다운로드 |
| `Ctrl` + `Shift` + `S` | 아카이브 저장 창 열기 |
| `Ctrl` + `Enter` (저장 창에서) | 아카이브에 저장 |
| `Esc` | 저장 창 닫기, 전체화면 종료, 드래그 취소 |

## 사용 방법

1. 이 저장소를 클론하거나 `index.html`을 내려받아 브라우저로 엽니다. 또는 GitHub Pages로 배포한 주소에 접속합니다.
   - 저장소 `Settings` → `Pages`에서 배포할 브랜치를 지정하면 서버 없이 바로 웹에서 쓸 수 있습니다.
2. 왼쪽 패널에 텍스트(또는 HTML)를 입력하고 스타일을 조절합니다.
3. 미리보기 오른쪽 아래 버튼으로 **클립보드 복사 / 다운로드 / 아카이브 저장**을 합니다. 마우스를 올리면 버튼이 나타납니다.

## 캡처 방식 (자체 캡처 / 서버 캡처)

### 자체 캡처 (기본)
[modern-screenshot](https://github.com/qq15725/modern-screenshot)으로 **사용자의 브라우저 안에서** 카드를 이미지로 만듭니다.
카드를 숨겨진 iframe에 복제한 뒤 웹폰트를 문서에 직접 넣고(임베드) 캡처하기 때문에 폰트가 깨지지 않습니다.
이때 카드에 **실제로 쓰인 글자와 두께에 해당하는 폰트 조각만** 골라서 넣기 때문에 미리보기와 같은 폰트로 빠르게 캡처됩니다.
서버를 거치지 않아 빠르고, 횟수 제한도 없습니다.

### 서버 캡처 (선택)
따로 구축한 캡처 서버(예: Cloudflare Worker + Browser Rendering)에 카드 HTML을 보내고, 서버의 실제 Chromium 브라우저가 찍은 스크린샷을 받아옵니다.

- `설정 › 시스템 및 서버 캡쳐 설정`에서 Worker 주소와 보안 토큰(선택)을 입력하고 저장합니다.
- 미리보기 오른쪽 아래의 `서버 캡쳐` 체크박스로 켜고 끕니다.
- 서버 캡처에 실패하면 자동으로 자체 캡처로 대체합니다.
- `오늘 사용량`에서 서버의 일일 사용 시간을 확인할 수 있습니다. 서버가 지원하는 경우에만 표시됩니다.
- 서버 코드는 이 저장소에 포함되어 있지 않으므로 직접 구축해야 합니다.

| | 자체 캡처 | 서버 캡처 |
|---|---|---|
| 속도 | 빠름 (내 브라우저에서 처리) | 느림 (업로드 + 서버 브라우저 실행 + 폰트 다운로드) |
| 결과물 | DOM을 SVG로 바꿔 다시 그리므로, 일부 CSS 효과나 줄바꿈이 조금 다르게 나올 수 있음 | 실제 Chromium 화면 그대로 |
| 제한 | 없음 | 서버의 사용량 한도를 따름 |

## 데이터 저장 및 백업

| 데이터 | 저장 위치 |
|---|---|
| 편집 설정·기본값·환경설정 | `localStorage` (브라우저·기기별로 따로 저장) |
| 아카이브 카드 | `IndexedDB` (브라우저·기기별로 따로 저장) |

브라우저 데이터를 지우거나 다른 기기로 옮길 때를 대비해, 아카이브 탭의 **백업 저장**으로 정기적으로 JSON 백업을 받아 두세요.
다른 기기에서는 **데이터 복구**로 그 파일을 불러오면 됩니다. 같은 카드는 덮어쓰고, 없던 카드는 추가합니다.

## 기술 스택

- **Vanilla JavaScript**: 프레임워크 없이 단일 HTML 파일로 동작
- **Tailwind CSS (CDN)**: HTML 뷰어 모드에서 붙여넣은 코드의 Tailwind 클래스를 렌더링하는 데 사용
- **웹폰트**: Google Fonts(Noto Sans/Serif KR, Gowun Dodum, Nanum Myeongjo, IBM Plex Sans KR, Nanum Gothic, Gothic A1, Do Hyeon, Song Myung, Black Han Sans, JetBrains Mono), Pretendard, Galmuri, KoPubWorld 돋움·바탕(한국출판인회의)
- [**modern-screenshot**](https://github.com/qq15725/modern-screenshot): DOM을 PNG로 캡처
- **IndexedDB / localStorage**: 아카이브와 설정 저장

## 주의 사항

- 모든 데이터는 **사용자의 브라우저에만 저장**되며, 서버로 전송되지 않습니다. 단, 서버 캡처를 켜면 캡처할 카드 내용이 설정한 서버로 전송됩니다.
- 시크릿(비공개) 모드에서는 창을 닫으면 저장한 데이터가 사라질 수 있습니다.
- KoPub 폰트는 글자 조각으로 나뉘어 있지 않아서, 처음 쓸 때 두께 하나당 약 2~3MB를 내려받습니다. 한 번 받은 뒤에는 브라우저에 저장되어 빨라집니다.
- 큰 배경·오버레이 이미지를 쓰면 `localStorage` 자동 저장이 용량 한도에 걸릴 수 있습니다. 이때는 이미지를 빼고 나머지 설정만 자동 저장합니다. 아카이브에 저장한 카드에는 이미지도 그대로 남습니다.
