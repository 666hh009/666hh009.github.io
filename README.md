# AI Archive Pro

AI와 나눈 대화나 HTML 코드를 예쁜 카드(이미지)로 꾸며서 저장·공유할 수 있는 **브라우저 기반 발췌·아카이빙 도구**입니다.
별도 설치나 빌드 과정 없이 HTML 파일 하나로 동작하며, GitHub Pages 등에 그대로 올려서 바로 사용할 수 있습니다.

> 텍스트/HTML을 입력 → 폰트·배경·오버레이·워터마크로 꾸미기 → 이미지로 캡처 → 로컬 아카이브(갤러리)에 저장, 이 흐름을 하나의 화면에서 처리합니다.

## 주요 기능

### 1. 발췌기 (카드 제작)
- **텍스트 모드 / HTML 뷰어 모드** 전환 지원
  - 텍스트 모드: 대화 내용을 그대로 붙여넣어 카드로 변환
  - HTML 뷰어 모드: HTML 코드를 그대로 붙여넣어 렌더링된 형태로 카드 제작
- **텍스트 편집 도구**: 굵게, 기울임, 엠대시(—), 가로 구분선 삽입
- **형광펜 하이라이트**: 원하는 텍스트를 드래그 후 색상·투명도를 지정해 하이라이트 처리
- **텍스트 그림자(Drop Shadow)**: 색상, 진하기, 흐림 정도, Y 위치 조절로 가독성 향상

### 2. 타이포그래피 커스터마이징
- 폰트 선택(명조체, 고딕체, 고운돋움, 나눔명조, 프리텐다드) 및 **커스텀 폰트 업로드**(ttf/otf/woff)
- 글자 크기, 줄 간격, 자간, 장평, 문단 간격, 내부 여백 조절
- 정렬(왼쪽/가운데/오른쪽) 및 줄바꿈 단위(단어/글자) 지정
- 텍스트 위치를 드래그하거나 X·Y 좌표를 직접 입력해 미세 조정

### 3. HTML 뷰어 레이아웃
- HTML 모드일 때 상하좌우 여백, 콘텐츠 배율 조절
- 드래그로 콘텐츠 위치 이동
- **컨테이너 위치 강제 해제**: 붙여넣은 HTML 최상위 태그에 걸린 `position`/`margin` 등의 고정 스타일을 무력화해 카드 중앙에 배치

### 4. 오버레이 이미지 (크롭 / 필터)
- 이미지를 업로드해 원하는 크기·둥근 모서리(radius)의 틀에 배치
- 틀 위치와 내부 이미지의 위치·확대(드래그 + 휠 줌)를 독립적으로 조절
- 필터 색상과 투명도로 이미지 위에 톤 오버레이 적용

### 5. 출처 표시 (워터마크)
- 캐릭터명 · 제작자명 텍스트 입력
- 글자 크기·색상 지정, 드래그 또는 좌표 입력으로 위치 조정

### 6. 카드/배경 설정
- 카드 가로·세로 크기(px) 지정
- 단색 배경 또는 배경 이미지 업로드
- 배경 이미지 드래그 이동 + 휠 확대/축소 (민감도 조절 가능)
- 배경 어둡기(Dim) 조절
- 미리보기 배율 슬라이더 및 **전체화면 모드**

### 7. 캡처 및 내보내기
- [modern-screenshot](https://github.com/qq15725/modern-screenshot) 라이브러리를 이용한 고품질 PNG 캡처
- 클립보드로 즉시 복사 또는 PNG 파일로 다운로드
- 웹폰트를 캡처 시점에 임베드하여 폰트 깨짐 방지

### 8. 아카이브 (갤러리)
- 완성한 카드를 태그·메모와 함께 **브라우저 내 IndexedDB**에 저장
- 태그/메모로 검색, 최신순·오래된순 정렬
- 저장된 카드 불러오기(재편집), 개별 다운로드, 삭제
- 전체 데이터 **JSON 백업(내보내기) / 복구(가져오기)** 지원

### 9. 시스템 편의 기능
- 입력 중이던 설정을 `localStorage`에 자동 저장(새로고침해도 유지)
- 타이포그래피/배경 설정을 각각 "기본값"으로 저장 후 언제든 초기화 가능
- 전체 설정 공장 초기화(단, 작성한 텍스트·코드 내용은 유지)

## 화면 구성

| 탭 | 설명 |
|---|---|
| **발췌기** | 좌측 컨트롤 패널(입력·스타일링)과 우측 실시간 미리보기 패널로 구성된 카드 제작 화면 |
| **아카이브** | 저장된 카드들을 검색·정렬·관리하는 갤러리 화면 |

## 기술 스택

- **Vanilla JavaScript** (프레임워크 없이 단일 HTML 파일로 동작)
- **Tailwind CSS** (CDN)
- **Google Fonts** (Noto Sans/Serif KR, Gowun Dodum, Nanum Myeongjo, JetBrains Mono) + **Pretendard**
- [**modern-screenshot**](https://github.com/qq15725/modern-screenshot) – DOM을 PNG/JPEG로 캡처
- **IndexedDB** – 아카이브(갤러리) 저장소
- **localStorage** – 사용자 설정 자동 저장 및 기본값 관리

---

## 사용 방법

별도의 설치나 빌드 과정이 필요 없습니다.

1. 이 저장소를 클론하거나 HTML 파일을 다운로드합니다.
2. 브라우저에서 HTML 파일을 직접 열거나, **GitHub Pages**로 배포해 접속합니다.
   - GitHub 저장소 `Settings` → `Pages`에서 배포할 브랜치를 지정하면 별도 서버 없이 바로 웹에서 사용할 수 있습니다.
3. 좌측 패널에서 텍스트(또는 HTML)를 입력하고, 스타일을 조절합니다.
4. 우측 하단 버튼으로 클립보드 복사, 다운로드, 또는 아카이브 저장을 진행합니다.

## 서버 캡처 (선택 사항)

기본적으로는 브라우저 내에서 자체적으로 캡처(샌드박스 iframe 렌더링)를 수행하지만, 별도의 **Cloudflare Worker** 등 캡처 서버 주소를 등록하면 서버 측 렌더링을 통해 더 정확한 캡처 결과를 얻을 수 있습니다.

- `시스템 및 서버 캡쳐 설정` 섹션에서 Worker 주소와 (선택) 보안 토큰을 입력 후 저장
- 우측 하단 `서버 캡쳐` 체크박스를 켜면 다운로드 시 서버를 통해 캡처
- 서버 캡처가 실패하면 자동으로 자체 캡처(샌드박스 방식)로 대체됩니다
- 서버 주소는 이 저장소에 포함되어 있지 않으며, 사용자가 직접 별도로 구축해야 합니다

## 데이터 저장 및 백업

- 스타일 설정: `localStorage`에 자동 저장 (브라우저/기기별로 별도 저장됨)
- 저장한 카드(아카이브): `IndexedDB`에 저장 (브라우저/기기별로 별도 저장됨)
- 브라우저 데이터를 삭제하거나 다른 기기·브라우저로 옮길 경우를 대비해, 아카이브 탭의 **백업 저장(JSON 내보내기)** 기능으로 주기적으로 백업하는 것을 권장합니다.

---

## 주의 사항

- 모든 데이터는 **로컬 브라우저에만 저장**되며 별도의 백엔드 서버로 전송되지 않습니다(서버 캡처 기능을 별도로 설정한 경우는 제외).
- 시크릿/비공개 브라우징 모드에서는 저장된 데이터가 세션 종료 후 사라질 수 있습니다.
- 대용량 배경/오버레이 이미지가 많이 누적되면 `localStorage` 자동 저장이 용량 제한에 걸릴 수 있습니다(이 경우 이미지 정보는 제외하고 저장됩니다).
